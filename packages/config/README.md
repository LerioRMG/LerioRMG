# @honey-garden/config

Riservato a configurazioni condivise future (es. regole ESLint/Prettier comuni tra `apps/api` e
`apps/web`). Attualmente ogni app mantiene la propria configurazione TypeScript/ESLint per
semplicità del monorepo; questo package è il punto di estensione naturale quando le configurazioni
cresceranno e converrà centralizzarle.
